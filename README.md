A small program that writes one single-line one-star review (151 characters) to `/output/entry.txt`: a deadpan complaint against Monday — it arrives on time every week, takes a full day, and offers no refund for the hours it wastes. The reviewer never ordered it, and it will be back next week anyway.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
